Methodology

Approach

This analysis employed an inductive thematic analysis following the six-phase framework of Braun & Clarke (2006). Thematic analysis is a method for identifying, analysing, and reporting patterns (themes) within data; this approach treats themes as patterns of shared meaning unified by a central concept or idea.

Process
  1. Familiarisation — Transcripts loaded and segmented into analytical units (speaker turns or paragraph blocks of 30–400 words).
  2. Generating initial codes — Each segment coded inductively using claude-haiku-4-5; 1–3 codes generated per segment capturing semantic and latent meaning.
  3. Searching for themes — All codes submitted to claude-opus-4-7 (with extended thinking) for semantic clustering into candidate themes.
  4. Reviewing themes — Each candidate theme reviewed against the coded segments; representative quotes identified.
  5. Defining & naming themes — Final theme names and descriptions written by claude-opus-4-7 in academic register, refined with adaptive reasoning.
  6. Producing the report — This interactive HTML report plus Excel and JSON exports.
